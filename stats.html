OPEN GOOGLE ANALYTICS ↗

Connect tracking

1. Create a free Google Analytics 4 property for summitcountysports.com.
2. Add a Web data stream, then copy the Measurement ID (it starts with G-).
3. Add your ID to content/site.json as "ga4_measurement_id": "G-XXXXXXXXXX" (including the comma after the preceding field).
4. The next GitHub Pages build installs tracking across site pages. Check Google Analytics → Realtime.
EDIT ANALYTICS SETTING ↗
This is an unlisted setup page, not a password-protected admin dashboard. Don't put credentials or private analytics data here. Tracking starts only after an ID is configured; historical visitor counts can't be recovered.
